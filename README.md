# multiagent_autonomous_design
An implementation of multi-agent autonomous design framework using ontological knowledge graphs as grounding agents for design iteration, evaluation, and review
Arxiv version of manuscript can be found here: https://arxiv.org/abs/2511.03179

# Getting started
1. Install the following packages for quick start: pip install crewai 'crewai[tools]' 'crewai[google-genai]' 'crewai[anthropic]' 'crewai[litellm]' ollama scipy matplotlib aerosandbox termcolor einops groq natsort scikit-image scikit-learn seaborn langchain langchain-community pypdf pyvis yachalk neuralfoil pandas pyDOE3
2. Add your LLM API keys in main.py
3. run main.py
